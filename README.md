# backend-api-concepts

Learn-by-doing examples and exercises for core backend API concepts.

What you'll learn
- API design, routing, validation
- Auth & authorization (JWT, API keys)
- Testing (unit & integration)
- Observability, caching, background jobs
- Deployment (Docker, CI)

Quick start
1. git clone https://github.com/mithra0612/backend-api-concepts.git
2. Open /examples for language-specific samples and follow each example README
3. Work through /exercises and run the included tests
